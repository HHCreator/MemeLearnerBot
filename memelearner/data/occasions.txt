# 比赛里的场面：MemeLearnerBot 用它给每个学会的梗标上什么时候说（py -m memelearner uses）。
#
# 一行一个场面：等号左边是场面的名字，右边是什么样的场面，模型照右边的说明给梗挑场面。
#   - 名字短一点，别和别的场面重名；说明写清楚就行，模型看的就是它。
#   - 可以加新的场面（比如「残局 = CS2 或无畏契约一个人打几个的残局」），也可以改说明。
#   - 去掉一个场面以后，标了它、又没有别的场面的梗，下次 py -m memelearner uses 会重新标；
#     你打过勾的梗不会被改，要自己在页面上改。
#   - # 后面的是说明，bot 不看。改完存成 UTF-8（记事本默认就是）。
#
# Occasions: the moments of a match a meme can be said in, one a line, "name = what it is".

秀了 = 选手或战队打出精彩操作、关键击杀，打得很好
打得烂 = 选手或战队失误、送人头、被单杀、决策离谱，打得很差
碾压 = 一方优势很大，把对面压着打，比赛没有悬念
翻盘 = 劣势的一方追回来、逆转，或者眼看要被翻盘
要输了 = 局势崩了、快输了、大势已去
赢了 = 一局或一场比赛刚赢下来、夺冠
输了 = 一局或一场比赛刚输掉、被淘汰
要打团 = 大团战、关键时刻、精彩场面马上要来
离谱 = 出人意料、看不懂的操作或局面，让人震惊或者哭笑不得
BP = 选英雄、禁英雄的时候，或者在议论阵容和英雄
开局 = 比赛开始前、刚开始，在等开场或者介绍选手
加油 = 给选手或战队打气、助威
预测 = 猜谁会赢、看好或者唱衰谁（包括毒奶和怕毒奶）
回看 = 已经知道比赛结果的人回来看录像，事后调侃
名场面 = 让人想起以前的比赛、经典时刻或者老梗
解说 = 在议论解说、主播、直播间或者广告
现场 = 在议论现场观众、场馆、气氛，或者弹幕里大家一起刷屏
吵架 = 在弹幕里回怼、嘲讽别的观众，或者和别的粉丝吵
叫人 = 只是在叫某个选手、战队（外号、尊称、黑称），他一出场或者一有动作就刷
