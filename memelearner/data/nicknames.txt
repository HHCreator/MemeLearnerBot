# 选手外号表：MemeLearnerBot 用它认出说法里的选手，比如「超威同意了」「三叔不同意」里的超威和三叔。
#
# 一行一个选手：等号左边是选手（写他的 ID），右边是他的外号，用逗号隔开（, ， 、 或空格都行）。
#   - 选手的 ID 自己也算一个外号，不用再写。
#   - 一个选手可以写好几行，比如在最后加一行「Chovy = 超大哥」。
#   - 大小写、全角半角都一样；重复的字母算一个，所以 chooooovy、chooovy 和 chovy 是同一个外号。
#   - 战队也可以这样写（IG = 埃及）。
#   - 一个字的外号（兰）也行，但它在别的词里也会被认成外号（荷兰）。
#   - # 后面的是说明，bot 不看。改完存成 UTF-8（记事本默认就是）。
#
# Player nicknames: one player a line, "Player = nickname, nickname, ...".
