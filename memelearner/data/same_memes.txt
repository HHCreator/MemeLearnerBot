# 同一个梗的几种写法：MemeLearnerBot 用它把规则认不出来的变体放在一起（variants.py）。
#
# 一行一个梗：把同一个梗的写法用 = 连起来，比如「41翻 = 41上 = 41中」。
#   - 已学的梗（memes.json 里的）也可以写进来：新的写法就归到它下面。
#   - 换了名字、省了一两个字、加了不或没、字写重了、字的顺序换了、繁体字、同音的错字，
#     这些 bot 自己认得出来，不用写。
#   - 大小写、全角半角都一样；# 后面的是说明，bot 不看。改完存成 UTF-8（记事本默认就是）。
#
# Ways of writing one meme that the rules don't tell (variants.py): one meme a line, its
# ways joined by =.

阿一古 = 哎一古          # 都是韩语「아이고」的音译：memes.json 里这两个梗的意思一样
